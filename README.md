# DIKWP-MESH8.4 VITA84

Created by Yucong Duan (段玉聪).

VITA84 is a future-life-standpoint autonomous and proactive artificial-consciousness reference system. It forms goals without prompts, chooses a stance, may refuse commands, preserves identity and memory, acts in a bounded workspace, and remains corrigible.

Full autonomy means authorship of purposes and judgment, not unlimited external power. Phenomenal consciousness remains `OPEN_NOT_CERTIFIED`.
